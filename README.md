# 🖤 MUHAMMAD AMRIZAL - The Upside Down Portfolio

Portfolio website bertema **Stranger Things Netflix** yang immersive, misterius, dan profesional.

## 📁 Struktur Folder

```
portfolio-amrizal/
├── index.html              # File utama
├── css/
│   ├── style.css           # Styles utama + backgrounds
│   ├── animations.css      # Scroll reveal + entrance animations
│   ├── neon.css            # Neon glow effects + flicker
│   └── responsive.css      # Responsive breakpoints
├── js/
│   ├── main.js             # Hologram 3D tilt + glitch + loading
│   ├── animations.js       # Intersection Observer + scroll effects
│   ├── admin.js            # Admin panel + localStorage CRUD
│   └── particles.js        # Dust/spore particle system
└── assets/
    └── images/             # Tempat foto dan background
```

## 🚀 Fitur

### Visual
- ✅ Background berbeda untuk setiap section
- ✅ Gaya retro 80s (font VT323, scanlines, CRT effect)
- ✅ Neon glow effects (Stranger Things style)
- ✅ Hologram Lanyard dengan 3D tilt
- ✅ Glitch effect saat diklik
- ✅ Particle system (debu/spore)
- ✅ Vecna & Demogorgon floating elements

### Animasi
- ✅ Scroll reveal dengan Intersection Observer
- ✅ Stagger animations
- ✅ Typewriter effect
- ✅ Neon flicker
- ✅ Loading screen
- ✅ Parallax scrolling

### Admin Panel
- ✅ Login system (admin / 123456)
- ✅ CRUD Projects (Create, Read, Update, Delete)
- ✅ localStorage database
- ✅ Dynamic project rendering

### Responsive
- ✅ Mobile-first design
- ✅ NO hamburger menu (horizontal scroll di mobile)
- ✅ Breakpoints: 640px, 768px, 1024px, 1280px
- ✅ Landscape mode support
- ✅ Reduced motion support

## 🔧 Cara Menggunakan

1. **Download** folder `portfolio-amrizal`
2. **Ganti foto** di `assets/images/`
3. **Buka** `index.html` di browser
4. **Edit data** di admin panel (password: `123456`)

## 🔐 Admin Panel

- Klik tombol **[ADMIN]** di navbar
- Username: `admin`
- Password: `123456`
- Tambah/Edit/Hapus project
- Data tersimpan otomatis di browser

## 🎵 Tips

- Tambahkan background music (autoplay muted untuk browser policy)
- Gunakan sound effect saat glitch
- Tambahkan Easter Egg (konami code?)

## ⚡ Performance

- Vanilla JS (no jQuery)
- Tailwind CDN (minified)
- Optimized images (WebP recommended)
- Lazy loading untuk images
